# 🚀 Bullet Hell Arcade (WelcomeScreen)

Динамичный аркадный **Bullet Hell / Shoot 'em up** на Python и Pygame с многофазными боссами, системой прокачки, режимом тренировки и хардкорными уровнями сложности.

---

## ✨ Особенности игры

- **Интенсивный Bullet Hell-геймплей**: уворачивайтесь от плотных геометрических паттернов, вращающихся лазеров, шахматных ловушек и самонаводящихся мин.
- **Эпические боссы с уникальными фазами**: сражения с нарастающей сложностью, включая финального Красного босса с 9+ уникальными фазами атак.
- **Гибкая система сложности**: от классического прохождения до беспощадных режимов **Infernum** и **Masochist**, меняющих скорость и плотность паттернов.
- **Режим тренировки**: отрабатывайте конкретные фазы боссов без необходимости проходить весь уровень заново.

---

## 🎮 Как запустить игру

### Вариант 1: Готовая сборка для Windows (без установки Python)
1. Перейдите в раздел **[Releases](../../releases)** справа.
2. Скачайте последнюю версию `.exe` (или архив с игрой).
3. Запустите файл и играйте.

### Вариант 2: Запуск из исходного кода
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd WelcomeScreen-BulletHell
   ```
2. Установите библиотеку `pygame`:
   ```bash
   pip install pygame
   ```
3. Запустите главный скрипт:
   ```bash
   python script.py
   ```

## 🕹️ Управление

- **Стрелки / WASD** — перемещение корабля
- **Пробел / ЛКМ** — стрельба
- **Shift** — точное замедление (фокус-режим для уворота между пулями)
- **Esc** — пауза / выход в меню

## 🛠️ Стек технологий

- **Python 3**
