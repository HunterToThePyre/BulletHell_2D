# Пулевой ад: ФОРМАция

Неоновый вертикальный скролл-шутер в жанре **Bullet Hell** (формат арены `TATE`) на Python и `pygame-ce` 
с процедурной графикой, синтезированным звуком, 6 уникальными персонажами и 3 многофазными боссами.

---

## Инструкция по запуску и сборке

### Требования
* **Python 3.10+** (протестировано на Python 3.14)
* Библиотека **`pygame-ce`** (или классический `pygame`)

### Запуск из исходного кода
1. Установите зависимость в терминале:
   ```bash
   pip install pygame-ce
   ```
2. Запустите главный файл из корня проекта:
   ```bash
   python script.py
   ```

### Сборка в автономный `.exe` (Windows)
1. Установите упаковщик:
   ```bash
   pip install pyinstaller
   ```
2. Выполните команду сборки из корня проекта (при наличии `icon.ico`):
   ```bash
   pyinstaller --onefile --windowed --icon=icon.ico --collect-all pygame --name="BulletHellFormacia" script.py
   ```
   Готовый исполняемый файл появится в папке `dist/`.

## Схема управления

| Клавиша | Действие |
| :--- | :--- |
| **`W` `A` `S` `D`** / **Стрелки** | Перемещение по игровой арене |
| **`Shift`** (удержание) | Режим фокусировки (замедление скорости вдвое для точного уклонения) |
| **`C`** | Энергетический щит (временная неуязвимость с перезарядкой) |
| **`V`** | Уникальная активная способность персонажа |
| **`B`** | Ультимативная способность персонажа |
| **`ESC`** / **`P`** | Пауза во время боя |
| **`R`** / **`К`** | Быстрый выход в меню тренировки (в режиме обучения) |
| **ЛКМ** | Навигация по меню и уничтожение ботов на фоновой арене главного меню |

## Архитектура проекта

### Корень проекта
* **`script.py`** — отвечает за запуск игры, главный цикл (`60 FPS`), переключение экранов (меню, бой, пауза,
* победа/поражение) и синхронизацию музыки с текущим состоянием.
* **`save_data.json`** — отвечает за хранение прогресса игрока между запусками:
* статистику убийств, время в игре, победы на сложностях и флаг показа дисклеймера.

### Папка `objects/` (Игрок)
* **`objects/objects.py`** — отвечает за реэкспорт класса `Player` для удобного импорта из главного скрипта.
* **`objects/objects_player_base.py`** — отвечает за модельку игрока, управление движением (`WASD` / стрелки,
* замедление на `Shift`), активацию щита (`C`) и таймеры способностей.

### Папка `player/` (Атаки и скиллы игрока)
* **`player/player_shooting.py`** — отвечает за автоматическую стрельбу всех 6 персонажей,
* векторное наведение на врагов и стрельбу от лица живых клонов.
* **`player/player_skills.py`** — отвечает за уникальные активные способности персонажей на клавиши `V` и `B`,
* временные баффы скорости и вращение орбитальных щитов.
* **`player/player_projectiles.py`** — отвечает за поведение и отрисовку всех снарядов игрока: обычных пуль,
* гигантских разрушающих сфер, очищающих волн, орбитальных щитов и клонов.

### Папка `play/` (Ядро геймплея, враги и боссы)
* **`play/constants.py`** — отвечает за глобальные настройки окна, иконку приложения, цветовую палитру, шрифты,
* размеры арены `TATE` и группы спрайтов.
* **`play/game_data.py`** — отвечает за загрузку/сохранение JSON-прогресса, характеристики всех 6 персонажей,
* проверку условий их разблокировки и полный сброс сохранения.
* **`play/game_loop.py`** — отвечает за ход боя и тренировки: спавн волн врагов по таймеру,
* призыв боссов в конце каждой волны и обновление всех групп спрайтов.
* **`play/combat_fx.py`** — отвечает за расчёт попаданий и урона, обработку гибели врагов/боссов,
* неуязвимость при ударе и отрисовку неонового свечения объектов.
* **`play/gameplay_extras.py`** — отвечает за дополнительные механики:
* комбо-множитель очков, систему «грейза» (пролёт вплотную к пулям),
* магнитные бонусы (`+1 HP`, `-КД`, `ТЕМП`) и всплывающие цифры урона.
* **`play/enemies.py`** — отвечает за 12 видов обычных врагов, их траектории движения (змейка, зигзаг,
* пролёт) и уникальные паттерны стрельбы.
* **`play/enemy_projectiles.py`** — отвечает за базовые вражеские пули, расширяющиеся сферы,
* энергетические связки между снарядами и лазерные лучи с фазой предупреждения.
* **`play/boss.py`** — отвечает за логику и 3 фазы атак первого мини-босса (**Синий круг**)
* а также базовый шаблон босса.
* **`play/purple_boss.py`** — отвечает за 4 фазы атак второго мини-босса (**Фиолетовый круг**):
* лазеры, телепортацию в центр арены, расширяющиеся кольца и угловой обстрел.
* **`play/red_boss.py`** — отвечает за каркас финального босса (**Красный круг**),
* его перемещение и переключение между 9 фазами.
* **`play/red_boss_attacks.py`** — отвечает за сценарии всех 9 фаз атак финального Красного босса
* (ловушка-сектор, вращающиеся лучи, шахматная матрица, гравитация и др.).
* **`play/red_boss_projectiles.py`** — отвечает за особые снаряды Красного босса:
* синусоидальные пули, фейерверки, самонаводящиеся мины, сжимающиеся кольца и вращающиеся лазеры.
* **`play/projectiles.py`** — отвечает за единый реэкспорт всех вражеских/игровых спрайтов и
* за тренировочный манекен (`Dummy`).

### Папка `play/` (Интерфейс, графика и звук)
* **`play/vfx.py`** — отвечает за звёздный параллакс-фон, систему частиц,
* ударные волны от взрывов и динамическую красную виньетку урона / низкого HP.
* **`play/vfx_shapes.py`** — отвечает за процедурную отрисовку неоновых фигур врагов,
* многослойных корпусов боссов, светящихся сфер и масок свечения.
* **`play/sfx.py`** — отвечает за процедурный синтез звуковых эффектов (выстрелы, взрывы, грейз, подбор бонусов)
* без внешних аудиофайлов.
* **`play/music_engine.py`** — отвечает за процедурную генерацию зацикленной фоновой музыки и
* плавное переключение треков под меню, волны и каждого босса.
* **`play/tate_hud.py`** — отвечает за отрисовку левой и правой боковых панелей боевого интерфейса:
* название сектора, шкалу HP, полосы перезарядки `C`/`V`/`B` и таймер волны.
* **`play/menu_scene.py`** — отвечает за живую демонстрационную битву на фоне главного меню,
* пульсирующий заголовок и энергетический барьер с вспышками.
* **`play/menu_screens.py`** — отвечает за главное меню, анимированные кнопки с неоновой подсветкой и
* экран подтверждения выхода с убегающей кнопкой «ДА».
* **`play/menu_subscreens.py`** — отвечает за подэкраны меню: последовательную разблокировку сложностей,
* сетку выбора персонажей с карточкой характеристик и экран статистики с настройкой громкости и сбросом сохранения.
* **`play/training_menu.py`** — отвечает за экран выбора тренировочного режима (манекен, волны 1–3 или любой из 3 боссов).
* **`play/disclaimer_screen.py`** — отвечает за стартовый экран предупреждения о вспышках (дисклеймер) и
* анимацию загрузки при запуске игры.
